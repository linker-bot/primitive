# 网页示教与原语操作指南（0.2.2）

本指南对应 0.2.2 的实际界面和控制行为。首次下载、配置环境和启动服务见
[安装与启动指南](getting-started.md)；视觉、力反馈、FK 和门控接入见
[感知原语配置](perception-setup.md)。没有硬件时可以使用 Mock 完成姿态编辑和迁移。

## 1. 页面入口、侧别与作用范围

服务启动后，以终端显示的主机和端口为准。例如本地端口为 8001 时：

| 地址路径 | 页面与用途 |
| --- | --- |
| `/` | 默认示教面板：手掌滑条、内置/感知原语、关键帧树、姿态库、迁移 |
| `/legacy` | 默认示教面板的兼容入口，功能相同 |
| `/workbench` | 扩展工作台：分类卡片、按住推进、自定义编辑器、原语菜单 |
| `/?side=left`、`/workbench?side=right` | 在已配置的机械手中明确选择一侧 |

默认页顶部的“按住推进与菜单”进入 `/workbench`；工作台的“返回示教面板”返回首页。
两页使用同一个后端和姿态库。打开另一页不会创建另一套独立控制器。

先确认页眉的**手型和左右侧**。侧别选项只包含启动时配置的手；姿态库按手型和左右侧
分别保存。切到左手后看不到右手的自定义手势，是正常的分库行为。

操作范围有三个容易忽略的区别：

- 执行原语、停止手势、保存姿态和导入导出，使用当前选中侧。
- **速度倍率由同一个面板实例配置的所有手共用。** 双手实例中修改速度会同时设置左右手，
  即使页面当前只显示右手。该值只用于本次运行，重启后使用启动参数。
- **编辑暂停在同一个面板实例内共用。** 首次进入示教或编辑时，会先停止该实例管理的所有手，
  再允许编辑者进行逐关节跟随或试播。默认页的“载入”和自定义回放也会进入这条编辑控制路径。
  只读观察模式不向手发送这些停止命令。

默认页要求先停止当前手势、退出本页示教，再切换手或页面；如果其他页面仍在编辑，
需先关闭对应编辑器。只读观察且本页未处于示教或播放时，可以直接浏览其他侧和页面，
不需要停止外部执行者或关闭其他页面的编辑器。工作台编辑器打开期间不能切侧。仅在工作台切换侧别查看状态，
不会自动停止另一侧的普通执行；需要停止时，回到该侧明确操作“停止手势”。

## 2. 内置、感知与自定义原语

| 类别 | 内容 | 入口 |
| --- | --- | --- |
| 默认原语 | `open`、`fist`、`pinch` 等预定义动作及基础原语 | 默认页“默认原语”；工作台同名分类 |
| 感知原语 | 视觉及力反馈相关原语，需要相应模型、反馈或目标 | 默认页“感知原语”；工作台“带感知原语” |
| 自定义原语 | 用户保存的一帧或多帧手势，按手型和侧别存储 | 默认页“姿态库”；工作台“自定义原语” |

本仓库保留 40 项注册原语，其中包含 13 项视觉和 5 项力控原语；具体手型支持范围见
[README 原语列表](../README.md)。注册数量不等于每个页面的卡片数量：例如
`named_pose` 是自定义姿态模板，页面用实际保存的手势替代它。

“不可用”会显示原因，例如当前手型不支持、反馈过期、缺少 FK、视觉目标或门控条件。
列表保留这些原语；补齐条件后才能执行。工作台若勾选“仅可用”，不可用项会暂时隐藏；
找不到某项时先清除搜索、取消“仅可用”，再检查分类和侧别。

“执行”会向当前侧提交动作。进入示教/编辑后，普通目录执行被暂停；先退出或关闭编辑器，
再根据提示“恢复控制”。恢复控制只是重新允许动作输入，原动作不会自动续播。

### 速度与按住推进

速度范围为 **0.25–3.0 倍**。1 倍按配置时长执行；0.5 倍名义运动时间约为原来的两倍。
运行中修改倍率影响后续运动时间，保持当前进度连续；不修改保存的关键帧时长、硬件限矩
或接触保护时间。双手共用倍率，作用范围见第 1 节。

支持有限轨迹的工作台卡片会出现“按住推进”：

1. 鼠标按住该按钮，轨迹向前推进；也可以聚焦按钮后按住空格或 Enter。
2. 松开即暂停，再次按住同一动作继续。
3. 到达终点后继续按住不会循环。松开后重新执行，会从当时的手姿重新开始。
4. 窗口失焦、标签页隐藏、键盘焦点离开按钮、指针取消或失联，会释放连续推进输入；
   回到页面后需要重新明确按下。

没有“按住推进”的原语不能通过该入口暂停续播。持续力控和感知闭环也不能任意跳到
某个百分比；它们必须维持自己的反馈和接触条件。

## 3. 默认示教面板：工具栏和关节编辑

| 控件 | 操作结果 | 是否驱动机械手 / 写入姿态库 |
| --- | --- | --- |
| 开始示教 | 进入编辑状态，初次进入时暂停实例内普通动作输入 | 可能先停止两手；本身不走到某个保存姿态；不写库 |
| 退出示教 | 释放本页编辑占用；若已无其他编辑器，则恢复普通输入 | 停止本页实时跟随；不自动重新播放；不写库 |
| 重新初始化 | 退出示教并执行当前侧 `init` | **会运动**；不写库 |
| 同步反馈 | 用当前实际反馈更新滑条目标 | 不下发新目标；不写库 |
| 关节滑条 / 数值输入 | 在示教可控状态下修改所选关节 | **会驱动修改的关节**；不自动保存 |
| 显示 0–255 / rad / ° | 切换数值显示单位 | 不运动；不改保存数据 |
| 显示保留关节 | 展示布局中通常隐藏的通道 | 只改显示，不增加硬件能力 |
| 新建手势 | 清空手势名和关键帧上下文，保留当前滑条 | 停止本页正在进行的跟随；尚未创建文件 |
| 取消编辑 | 清除当前编辑标记，保留选择和滑条 | 停止本页跟随；不撤销已保存的数据，也不等于退出示教 |

滑条只更新被修改的关节；“载入”一个整帧不会自动下发所有关节。
若想让手完整走到某一帧，使用下面的“回放”。

### 创建一个三帧手势

例如希望保存 `grip_demo`：

```text
grip_demo
├─ pre      1 秒
├─ grasp    2 秒
└─ release  1 秒
```

1. 选择对应手，点“新建手势”，填写 `grip_demo`。
2. 点“开始示教”，调节滑条准备第一帧。
3. 在“帧名”填 `pre`，时长填 `1`，点“＋ 添加”。**此时该帧已保存到库。**
4. 调整下一姿态，填 `grasp` 和 `2`，再次“＋ 添加”。
5. 最后添加 `release`，时长 `1`。
6. 在姿态库展开手势，核对帧数与顺序；点“播放全部”执行整个手势。

“添加中间态”记录你准备好的姿态，不根据前后帧自动生成插值姿态。新帧名追加在末尾；
**已有帧名覆盖原位**。例如已有 `A → C`，添加新帧 `B` 后得到 `A → C → B`，
再使用 B 行的“↑”移动一次得到 `A → B → C`。

“建议名”只填写尚未使用的帧名，不写库也不运动。“＋ 添加”成功后也会建议下一帧名，
便于继续录制。“保存”和“＋ 添加”使用相同的新增/覆盖规则；“＋ 添加”要求在示教状态，
“保存”适合修改现有帧。对多帧手势保存时，必须明确要更新的帧名。

`pre`、`grasp`、`hold` 都是名字，不自动开启抓取、力控或等待逻辑。
**时长表示从本段起点运动到这一帧目标的时间，不是到达后的停留时间。**
需要停留时，可再添加一个目标相同的后续帧，并设置它的时长。
上例总名义轨迹时间是 4 秒；0.5 倍速约 8 秒，实际完成还包含反馈到位确认。

### 姿态库逐按钮说明

| 位置与按钮 | 作用 | 动作 / 保存副作用 |
| --- | --- | --- |
| 手势前的 ▶ / ▼ | 展开、收起关键帧列表 | 只改显示 |
| 手势名称 / 关键帧名称 | 选择编辑对象，填写名称与时长等元信息 | **不载入已保存的关节值**；不写库 |
| 手势行“播放” / 编辑区“播放全部” | 从当前手姿开始按保存顺序执行所有帧 | **会运动**；不写库 |
| 手势行“编辑” | 载入该手势的最后一帧目标，进入示教 | 不自动走到该目标；可能停止原动作/跟随 |
| 关键帧行“回放” | 从当前手姿运动到该帧目标，单段 AUTO | **会运动**；不先执行前面的帧 |
| 关键帧行“定点” | 把该段预览切到段内 0% | **属于动作控制，可能回退**；详见下一节 |
| 关键帧行“载入” | 把该帧目标和时长载入滑条，进入示教 | 不自动走到目标；可能停止原动作/跟随 |
| 关键帧行 ↑ / ↓ | 与相邻帧交换顺序 | **立即写库**；不播放 |
| 关键帧行“改名” | 修改该帧名称 | **立即写库**；目标与顺序保留 |
| 关键帧行“删” | 删除该帧 | 确认后**立即写库**；最后一帧需通过“删除手势”删除 |
| 编辑区“保存” | 将编辑值写入指定手势/帧 | **立即写库**；不下发整帧动作 |
| 编辑区“删除手势” | 删除整个手势 | 确认后立即删除该手势条目 |
| “停止” / “停止手势” | 停止当前自定义播放 / 当前侧原语 | 动作控制；不删除保存数据 |

精确修改某帧的流程：**展开手势 → 对应帧“载入” → 调整关节或时长 → “保存”**。
仅点击帧名再保存，可能把编辑区原有的关节值覆盖到该帧。

姿态库下面的偏好：

- **保存时用滑条目标**：勾选时保存编辑目标，取消时保存当前实际反馈；手尚未到位时二者可能不同。
  “载入”会重新勾选它。
- **AUTO 播放结束后回到示教**：从示教进入普通自动播放，完成并确认到位后返回示教状态。
  它不把手送回初始姿态；进度控制和按住推进不按此规则自动退出。

## 4. “定点”和进度条的确切含义

“定点”对应**该段 progress=0**。假设当前手姿为 A，所选帧保存目标为 B：

```text
当前这次段预览：A ─────────────────→ B
               0%                 100%
```

首次点“定点”时，预览起点取进入时的当前手姿 A，通常保持在 A；100% 才对应 B。
同一段预览已经走到中间，再点“定点”会回到这次预览最初的 A，因而可能回退。
需要直接到 B 时，点该帧“回放”。

默认页的“全局进度”按每帧时长加权。对于 `pre=1s、grasp=2s、release=1s`：

| 帧 | 全局进度区间 | 本段局部进度 |
| --- | --- | --- |
| pre | 0%–25% | 0%–100% |
| grasp | 25%–75% | 0%–100% |
| release | 75%–100% | 0%–100% |

因此点 `grasp` 的“定点”，全局条显示约 25%，局部进度是 0%。这不能单独证明手已经处于
前一帧 `pre` 的保存目标。拖动跨段时，会为新段建立预览起点；系统不先自动走完被跳过的帧。
同一内容、同一帧的连续拖动复用原起点；换段、换保存版本或重新开始预览会重新取起点。

三处进度显示需要区分：

| 位置 | 用途 |
| --- | --- |
| 默认页“全局进度”滑条 | 直接选择已保存自定义手势的段与段内进度；**会控制动作** |
| 工作台“执行状态”进度条 | 显示当前动作整体进度；只读 |
| 工作台编辑器“预览进度”滑条 | 先“试播当前帧”或“试播整个动作”，再调节这次预览；**会控制动作** |

停止或预览失效后，旧进度请求不会恢复动作；工作台需重新试播建立有效预览。
修改工作台草稿后，应重新试播再拖动；单独拖滑条不会自动把新草稿换进已有预览。

## 5. 扩展工作台的编辑器和菜单

在 `/workbench` 点“新建原语”，或者在自定义卡片点“编辑”，进入多帧草稿编辑器。
进入编辑会先暂停普通动作，范围见第 1 节。

**这里的保存方式与默认页不同：**关键帧添加、移动、删除等操作先改内存草稿，
点击“保存原语”才整体写入库。关闭未保存的草稿时会询问是否放弃修改。

| 控件 | 作用 |
| --- | --- |
| 实时跟随 | 可控环境下打开编辑器时默认勾选；修改滑条/数值会驱动所改关节。取消勾选后只改草稿 |
| 帧标签 | 切换正在编辑的帧；停止当前跟随，不自动运动到该帧 |
| 添加帧 | 在末尾添加一个目标为关节限位内零值、时长 0.6 秒的新帧；不是读取当前手姿 |
| 复制当前帧 | 将当前帧目标和时长复制到末尾，并给出新名称 |
| 前移 / 后移 / 删除当前帧 | 只修改草稿中的顺序或内容；至少保留一帧 |
| 读取当前手姿 | 将新鲜反馈写入当前帧草稿；不自动保存、不发送动作 |
| 试播当前帧 / 试播整个动作 | 执行草稿中的单帧 / 全部帧；不要求先保存，**会运动** |
| 停止 | 停止此侧动作及实时跟随；不删除草稿 |
| 另存为 | 将名称改为带 `_copy` 的新名称并解除原版本关联；可继续修改名称，点“保存原语”才落盘 |
| 保存原语 | 保存整个草稿；保持编辑器打开，不自动执行 |
| 删除原语 | 确认后删除已保存的原语并关闭编辑器 |
| 关闭 | 释放本页编辑占用；未保存的内容按确认结果处理 |

草稿名称使用小写字母、数字和下划线；关键帧名以小写字母或下划线开头，不能重复。
名称最长 64 个字符，一个草稿包含 1–100 帧，每帧时长为 0.2–60 秒。保存遇到“版本已变化/冲突”时，重新读取最新姿态后再编辑，
避免覆盖另一页面的修改。

关闭工作台编辑器后，普通动作输入仍保持暂停。关闭所有编辑器，待停止确认完成后，
点“恢复控制”，再明确执行所需动作。页面断联不会自动恢复普通输入。

### 原语菜单

菜单用于组织常用执行入口。它按手型和左右侧分别保存，不改变原语本身。

1. 从下拉框选择原语，点“加入”。
2. 用菜单行 ↑ / ↓ 调整顺序，× 移除菜单项。
3. 点**“应用菜单”**持久保存；前两步只修改页面中的待保存菜单。
4. 没有打开编辑器、控制未暂停且焦点不在输入框时，数字键 **1–9** 执行相应菜单项。

移除菜单项不会删除自定义手势。数字键会实际提交执行，不只是选中高亮。

## 6. 姿态包迁移与出厂预设

默认页“跨机迁移”和工作台“姿态迁移”操作同一个姿态库。
这些按钮本身不播放动作；导入会修改磁盘上的库。

| 按钮 | 数据范围与结果 |
| --- | --- |
| 导出下载 / 导出姿态包 | 导出当前手型、当前侧的**整个已保存库**为 `.pose_bundle.json`，不是只导出选中手势 |
| 导入文件 / 导入姿态包 | 按手型、侧别过滤文件内容，再按冲突策略写入当前库 |
| 导入出厂预设 | 把当前手型配置中可导出的静态终态快照写为 `preset_*` 条目 |

搜索过滤不会缩小导出范围。包内包含已保存的目标、关键帧顺序、时长和说明，
不包含未保存草稿、当前速度倍率、驱动配置、模型权重或完整运行环境。
左右手应分别导出，再在目标机器对应手型、对应侧导入；不会自动镜像另一侧或转换不同手型。

冲突按**手势名称**判断：

| 策略 | 同名手势的处理 |
| --- | --- |
| 跳过已有 | 保留目标库已有版本，不导入该同名条目 |
| 覆盖 | 替换同名手势及其关键帧，不做逐帧自动合并 |
| 重命名导入 | 保留已有版本，将导入条目另存为如 `grip_demo_imp`，重复时继续编号 |

默认页“导入校验 checksum”检查包内条目是否与校验值相符，通常保持勾选。
工作台的文件导入始终启用该校验。手工修改文件后，原校验值可能不再匹配。
`imported=0、skipped=N` 可能表示全部同名或手型/侧别不匹配，不一定是损坏文件。

### 出厂预设为何只有部分原语

0.2.2 的 O6 配置可导入 11 项：

```text
preset_init         preset_open          preset_fist
preset_release      preset_relax_grip    preset_pinch
preset_index_pinch  preset_middle_pinch  preset_point
preset_ok_sign      preset_v_sign
```

数量随手型配置而定。这些条目提供可编辑的**最终目标和名义时长**，不包含原内置动作
全部阶段算法、视觉决策或力控闭环，也不决定内置原语目录的数量。
执行内置原语无需先导入出厂预设。

“跳过已有”只补充缺少的 `preset_*`；“覆盖”会重写同名 `preset_*`，包括你修改过的预设。
“重命名导入”只适用于文件，出厂预设按“跳过已有”处理。
重复导入且全部已存在时，可能显示 `factory imported=0`，表示没有新增条目。

跨机操作顺序：**源机器保存 → 选择侧别导出 → 复制文件 → 目标机器选择同手型同侧 →
选择冲突策略导入 → 检查关键帧顺序和时长 → 手动决定是否播放**。
升级前也可以分别导出两侧作为备份；更换安装目录时继续指定原来的
`HAND_GESTURE_POSE_DIR`，详见[安装与启动指南](getting-started.md)。

## 7. 状态提示和常见问题

| 提示 / 现象 | 含义与下一步 |
| --- | --- |
| 只读观察 | 不发送动作、速度或停止命令；仍可编辑保存姿态和迁移数据，因此不是文件只读模式 |
| 编辑期间动作输入已暂停 | 有编辑页占用，或编辑已退出但尚未恢复；关闭编辑器后按提示恢复控制 |
| 另一页面正在实时控制此手 | 单侧只允许一个实时编辑者；停止或关闭另一页面的跟随 |
| 当前关节反馈缺失或过期 | 不能可信地捕获手姿或开始跟随；检查驱动与反馈，Mock 则检查模拟服务状态 |
| 轨迹到达终点 / 等待机械手到位 | 名义轨迹结束，还在等待新鲜反馈确认 |
| 反馈已确认到位 | 已满足本次反馈到位检查 |
| 到位超时 | 不能确认目标已达到；检查反馈、控制器和实际姿态 |
| 进度在前进，真机不动 | 有反馈不等于运动控制器已激活；只读检查控制器和侧别，见[运行排查](workbench.md#真机播放排查) |
| 切侧后自定义库为空 | 检查手型、侧别、`HAND_GESTURE_POSE_DIR`；新目录不会自动读取旧目录 |
| 请先试播 / 试播已改变 | 工作台进度条没有当前有效预览，重新试播需要控制的草稿 |

网页“停止”表示停止该执行请求，不代替硬件急停；停止确认也不等于已经测得电机物理停稳。
关闭或刷新页面不应作为停止普通 AUTO 动作的操作方法：先明确停止，再退出编辑。
