# 0.2.2：手势运行时与网页工作台

## 功能

- 提供 40 项注册原语，包括 13 项视觉感知原语；各手型支持范围见 [README](../../README.md)。
  网页显示缺失的反馈、感知、FK 或门控条件。
- 网页支持自定义姿态、多关键帧编辑与回放、关键帧排序和重命名、姿态包导入导出及出厂预设。
- 支持 0.25–3.0 倍速、有限动作按住推进与松开暂停、自定义动作进度控制。
  持续感知和力控闭环不支持任意进度跳转；速度倍率不改变接触保护时间。
- 默认页面提供手掌滑条、关键帧树和姿态库，`/workbench` 提供扩展编辑器与原语菜单。
- 支持独立 Mock 和已有 ROS 驱动；安装包包含 O6 右手 URDF 与 meshes。

## 安装与兼容

安装与单手/双手启动见[安装指南](../getting-started.md)，网页操作见
[用户手册](../teach-panel-user-guide.md)，接口约定见[工作台说明](../workbench.md)。

- ROS 2 Jazzy 使用系统 Python 3.12 创建的独立 venv，安装 Pydantic 2 并保留系统 NumPy/SciPy。
- 保留 ROS 字符串命令、Float32 进度、旧面板 WebSocket 与姿态 CLI。
  新控制路径绑定执行身份，停止或失权后拒绝迟到的旧请求。
- 显式设置 `HAND_GESTURE_POSE_DIR`，按手型与左右侧存储；旧姿态目录不会自动迁移。
  升级前保留原数据，跨目录迁移使用姿态包。
- 版本复现以所用公开提交 SHA 为准；Python 包版本为 `0.2.2`。
- 原语实现及独立开发的工作台代码采用 MIT；O6 模型资源和 `hand_force_msg` 保留各自原有的
  Apache-2.0 许可，适用范围见 [NOTICE](../../NOTICE)。

## 已知限制

- 手掌布局在 390px 手机视口有横向溢出，建议使用桌面浏览器。
- 仅自带 O6 右手模型；O6 左手及其他手型需提供真实模型，不能用右手模型替代。
- 感知和力控闭环需要实际目标、反馈及门控条件；软件或 Mock 测试不能替代设备部署验证。
- 停止 ACK 表示执行器停止处理动作，不代表已经测得电机物理停稳。
